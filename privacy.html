Privacy policy

ServiceNow Quick Navigator by Alex
Last updated: November 8, 2026

Install from the Chrome Web Store

This extension helps you switch between ServiceNow instances and open saved navigation links. Your settings are stored in your Chrome profile. The extension does not send your configuration or ServiceNow URLs to Alex or to an analytics service.

Information used by the extension

The extension reads the active ServiceNow tab's URL to recognize its instance, build navigation destinations, and offer right-click actions. A URL can contain table names, filters, record IDs, or other values. These are processed locally. The extension does not read the contents of ServiceNow pages, sign-in forms, passwords, or cookies, and it does not maintain a browsing-history log.

Settings you enter or import may include instance hostnames and labels, projects, navigation paths, descriptions, folders, colors, keyboard shortcuts, and production markers. These settings and backup timestamps are saved using Chrome's local extension storage. Collapsed section preferences are saved in local storage. The extension does not use Chrome's synchronized storage.

Permissions

  • Storage: saves your configuration and preferences in your browser profile.
  • Context menus: lets you add instances and table links by right-clicking the extension icon.
  • ServiceNow site access: makes supported HTTP and HTTPS URLs under service-now.com and servicenow.com available for instance detection, switching, and table actions. It does not grant access to your ServiceNow account or bypass authentication.

Sharing and external services

The extension contains no analytics, advertising, tracking, or remotely loaded executable code. It does not sell user data or use it for advertising, credit decisions, or any unrelated purpose. Information is used only to provide the navigation and configuration features described here, in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Opening a link sends a normal browser request to the destination you chose, which is subject to that website's privacy policy. Links to SN Utils, OpenAI, and Ko-fi open only when you click them. No embedded analytics, payment widgets, or AI clients are loaded by the extension.

Exports, imports, and optional AI assistance

Export JSON creates a configuration file on your device. Import JSON reads the file you choose and saves its configuration locally. Exported navigation paths and descriptions may contain internal information, so review them before sharing.

The optional AI guide provides instructions you can give to a separate AI service. The extension does not upload files or contact that service. If you choose to share configuration or ServiceNow favorites exports with an AI service, its policies apply to the information you share.

Retention and removal

Saved settings remain in your Chrome profile until you edit or replace them, remove the extension's stored data, or uninstall the extension. Restore defaults replaces your saved configuration with the bundled defaults. Exported files remain wherever you saved them and must be deleted separately. Any browser or device backups you make are managed outside this extension.

Questions and updates

For questions, use the support contact provided on the extension's Chrome Web Store listing. This policy will be updated if the extension's data handling changes.
