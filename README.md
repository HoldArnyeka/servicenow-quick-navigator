# ServiceNow Quick Navigator by Alex

Public privacy policy for the Chrome extension.

[Read the privacy policy](https://holdarnyeka.github.io/servicenow-quick-navigator/privacy.html)

The extension helps users switch between their configured ServiceNow instances
and open reusable navigation links. Settings and URL processing stay in the
browser profile. See the policy for details.

ServiceNow Quick Navigator by Alex is an independent extension and is not
affiliated with, endorsed by, or sponsored by ServiceNow.
